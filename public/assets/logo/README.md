# GCMS — logo files

| File | When to use |
| --- | --- |
| `logo-primary.svg` | Default. Reports, docs, presentation title slides, official communication. |
| `logo-primary-inverted.svg` | Same as above, but for dark backgrounds. Splash screens, dark-mode UI. |
| `logo-stacked.svg` | Square contexts. Social-media avatars, app store icons, posters. |
| `logo-mark.svg` | Mark only, bevelled. Use at sizes ≥ 48 px. |
| `logo-mark-mono.svg` | Single-colour. Black-and-white printing, embossing, photocopies. |
| `favicon.svg` | Browser tab. Flat (no bevels) — they get muddy below 48 px. |
| `logo-readme-banner.svg` | GitHub README header. 1280 × 320, fills the column. |

## Colours

| Role | Hex |
| --- | --- |
| Navy (primary) | `#0F2A44` |
| Navy mid (bevel) | `#23527E` |
| Navy light (bevel highlight) | `#1A3C5E` |
| Oxblood (accent) | `#8B1E2D` |
| Gold (on dark only) | `#C9A646` |
| Parchment (on dark only) | `#F4EBD3` |
| Canvas (background) | `#FAF8F3` |

## Clear space + minimum size

- Maintain a margin equal to the height of the GCMS wordmark on all four sides.
- Use the full lockup at ≥ 220 px wide. Below this, switch to the stacked or mark-only variant.
- Below 48 px, use `favicon.svg` — the bevels turn to mush at small sizes.
